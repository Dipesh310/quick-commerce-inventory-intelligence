# Quick-Commerce Inventory & Discount Intelligence

An end-to-end data analytics pipeline and interactive decision-support dashboard analyzing **3,731 SKUs across 14 categories** from the Zepto quick-commerce catalog. Built with **DuckDB SQL**, **Python**, and **Streamlit**.

**Live App:** [Launch Interactive Dashboard] https://quick-commerce-inventory-intelligence.streamlit.app/

---

## Executive Summary & Key Findings

* **Active Inventory Footprint:** **₹22.43 Lakh** (`₹2,243,081`) across 3,731 valid SKUs (1 invalid ₹0 MRP row removed during ingestion).
* **Stockout Risk & Restock Sizing:** Overall out-of-stock (OOS) rate stands at **12.14%** (453 SKUs), led by **Biscuits (28.57% OOS)**. Restocking OOS items to their category median in-stock quantity represents an estimated **₹2.09 Lakh** (`₹208,806`) inventory unlock.
* **Promotional Margin Exposure:** Active inventory carries **₹2.50 Lakh** (`₹249,700`) in discount burn at an average discount of **7.9%**.
* **Data Quality Audit Catch:** Exploratory SQL profiling uncovered identical SKU distributions across duplicate category scrapes (*Personal Care / Paan Corner*, *Beverages / Dairy, Bread & Batter*, and *Munchies / Cooking Essentials*). The dashboard includes a live sidebar toggle to inspect deduplicated totals rather than reporting inflated figures blindly.

```text

├── data/
│   ├── raw/                  # zepto_v2.csv (raw Kaggle catalog)
│   └── processed/            # cleaned_zepto.parquet (generated by pipeline)
├── sql/
│   ├── 01_data_cleaning.sql  # Paise-to-INR conversion, anomaly filtering, discount audit
│   ├── 02_kpi_views.sql      # Category scorecards, weight tiers, discount bands
│   └── 03_deep_dives.sql     # High-MRP OOS sizing, pack-size unit price gaps, burn leaders
├── src/
│   └── pipeline.py           # Handles windows-1252 encoding, executes SQL, exports Parquet
├── app/
│   └── streamlit_app.py      # 3-tab interactive dashboard + What-If Restock & Margin Simulator
└── requirements.txt
```

## Dashboard Features

1. **Executive Overview:** Category-level inventory valuation, stockout concentration, and discount-band breakdown with a data-deduplication toggle.
2. **Pricing & Unit Economics:** Interactive MRP vs. actual discount scatter plot and multi-pack unit-price spread (`₹ per 100g`) analysis.
3. **What-If Simulator:**
   * **Priority Restock Simulator:** Model unlocked inventory value for the top *N* OOS SKUs at adjustable stock depths and export an actionable CSV restock plan.
   * **Discount Cap Simulator:** Estimate rupee-value discount burn saved by capping promotional discounts on in-stock SKUs.
